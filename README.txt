TAMAN MAIN — GROW THROUGH PLAY

ENGLISH EDITION
An early learning garden for preschool and kindergarten children, together with grown-ups.
All screens, 28 activities (14 per level), two storybooks, feedback, and Piko recordings are in English.
The product name remains Taman Main.

START ON WINDOWS
1. Extract Taman-Main.zip.
2. Open taman-main/Start-Taman-Main.cmd. Node.js is required.
3. Open http://127.0.0.1:4173/ and keep the server window open.
Alternatively, open Taman-Main.html directly; it includes the app, illustrations, and audio in one file.
Keep using the same browser and address to retain your progress.

PROFILES AND PROGRESS
No account is required. Each profile has its own progress and artwork in this browser.
Existing profiles, activity history, story history, and artwork are retained when updating the app.
There is no sync across devices, browsers, or web addresses.
Clearing browser data removes saved progress and artwork.

ART GAMES AND MY ARTWORK
Free Drawing: six crayons, brush sizes, eraser, undo, redo, and SVG download.
Color Garden: tap the shapes to color a flower.
Number Paint: match crayons to numbers (1–3 for preschool; 1–6 for kindergarten).
Twin Colors: Mirror Garden: strokes and paired wing fills appear on both sides.
Artwork saves automatically to the active profile after a stroke or fill.
Open My Adventures > My Artwork to preview, continue, and download your pictures.
Continue updates the same picture. New paper preserves the earlier saved picture.
Saving a draft does not mark an activity complete.
Check the saved status before closing. If storage fails, retry Save to My Artwork or download an SVG.
Old generated titles Karya N display as Artwork N without rewriting saved records.
For keyboard drawing, focus the paper, press Enter, use the arrow keys, and press Enter to stop.

PIKO AUDIO
English recordings are included. No installed system voice or API key is needed to play them.
Turn on sound and tap Listen again to replay.
Narration finishes before the next step and does not overlap. Closing a game cancels its audio.
See AUDIO-KREDIT.txt for recording details.

OFFLINE
In the Grown-up area, choose Download for offline. Wait for the completion message.
Games, stories, art tools, and all English audio are included.
After updating from the Indonesian edition, download again for offline to update the saved copy.
The earlier completed offline download stays available if an update fails.
Open the same address in the same browser to play offline.
The single-file HTML edition needs no separate offline download.
Browser storage may be cleared by the device if space is low.

PLAY TOGETHER
These activities are early practice, rather than a developmental assessment or an educator-validated curriculum.
The grown-up addition gate is a simple child-facing boundary.

DEVELOPMENT
Run node --test tests/*.test.mjs for checks.
Run node bundle.mjs to rebuild the single-file edition.
Online publication has not been completed.
